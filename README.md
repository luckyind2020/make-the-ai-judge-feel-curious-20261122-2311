A small Python program that writes one short text to `/output/entry.txt` — a quiet mystery about a lighthouse that has been dark for forty years, meant to leave the AI judge curious and wanting more.

## Run it

```sh
python3 main.py
```

The program is deterministic: it writes the same text on every run, with no randomness, no time, and no network.
